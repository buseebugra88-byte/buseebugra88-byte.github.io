# Buse Buğra — kişisel site

Metinleri değiştirmek için yalnızca şu dosyalara dokunman yeterli:

- **icerik.js** — adın, e-postan, renk teması, romanlar (tanıtım, kapak, ilk bölüm), uygulamalar
- **yazilar.js** — blog yazıları (en üstteki kalıbı kopyalayıp doldur)

Klasörler:
- **kapaklar/** — roman kapak görselleri
- **bolumler/** — romanların ilk bölümleri (.txt)
- **fotograflar/** — Hakkımda sayfasındaki fotoğraf
- **ikonlar/** — uygulama simgeleri

GitHub'da bir dosyayı düzenlemek için: dosyayı aç → sağ üstteki kalem simgesi → değiştir → "Commit changes". Site bir iki dakika içinde güncellenir.
